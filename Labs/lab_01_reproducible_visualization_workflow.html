  • Include 12 fictional counties. Schnauzer County, Quarto County, Clifton County, Creek County, Midtown County, Cascade County, Mustard County, Hydrant County, Dove County, French County, Green County, Corinth County

  • Include three regions: North, Central, and South. North Region, Central Region, South Region

  • Use set.seed(716).

  • Generate plausible values for population, visits, and vaccination coverage.

  • Calculate asthma visit rate per 100,000.

  • Round the rate to one decimal place.

  • Use tidy formatting.

Because we don’t want to manually generate random values for 12 counties, we’re going to generate codes for random selection. Each requested category will have its own code chunk instead of one large chunk to reduce errors and gradually build the dataset.

Vaccination Rates

Assigning vaccination coverage between 62% and 94%

county_health_data <- county_health_data %>%
  mutate(
vaccination_rate = round(
  runif(
    12,
    min = 62,
    max = 94
  ),
  1
)
)

Asthma Rates Per 100,000

Generating asthma visits proportionally with “runif” Calculating asthma visit rate per 100,000 people

county_health_data <- county_health_data %>%
  mutate(
    asthma_visits = round(
      adult_population * runif(
        12,
        min = 0.004,
        max = 0.018
     )
      ),
    
  asthma_visit_rate = round(
    asthma_visits / adult_population * 100000,
    1
  )
  )
