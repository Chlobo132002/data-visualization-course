Learning Objectives

You will create static and interactive public health maps with sf, maps, and leaflet.

Setup

Load tidyverse, sf, maps, leaflet, and htmltools.

library(tidyverse)
library(sf)

Part 1: Georgia County Boundaries

Use the maps package and convert Georgia county boundaries to an sf object.

georgia_counties <- maps::map(
  database = "county",
  regions = "georgia",
  plot = FALSE,
  fill = TRUE
) |>
  sf::st_as_sf() |>
  rename(county_id = ID) |>
  mutate(
    county_name = str_remove(county_id, "^georgia,"),
    county_name = str_to_title(county_name)
  )

ggplot(georgia_counties) +
  geom_sf(
    fill = "#E8F0F8",
    color = "white",
    linewidth = 0.25
)+
  labs(
    title = "Georgia County Boundaries",
    subtitle = "Geographi foundation for public health mapping",
    caption = "Source: maps R package"
  )+
  theme_void()

Part 7: Interactive Leaflet Map

Include:

  • basemap,
  • county polygons,
  • labels,
  • legend,
  • and highlight behavior.
# Convert county geometry for web mapping
county_leaflet <- sf::st_transform(
  county_map_data,
  4326
)
# Create vaccination coverage color palette
coverage_palette <- leaflet::colorNumeric(
  palette = "viridis",
  domain = county_leaflet$vaccination_rate,
  na.color = "#BDBDBD"
)
# Create county hover labels
county_labels <- paste0(
  "<strong>",
  htmltools::htmlEscape(county_leaflet$county_name),
  " County</strong>",
  "<br>Simulated vaccination coverage: ",
  round(county_leaflet$vaccination_rate, 1),
  "%",
  "<br>Simulated child population: ",
  scales::comma(county_leaflet$child_population)
) |>
  lapply(htmltools::HTML)
# Build interactive map
leaflet::leaflet(data = county_leaflet) |>
  leaflet::addProviderTiles(
    leaflet::providers$CartoDB.Positron
  ) |>
  leaflet::addPolygons(
    fillColor = ~coverage_palette(vaccination_rate),
    fillOpacity = 0.8,
    color = "white",
    weight = 0.6,
    label = county_labels,
    highlightOptions = leaflet::highlightOptions(
      weight = 2,
      color = "#333333",
      fillOpacity = 0.9,
      bringToFront = TRUE
    )
  ) |>
  leaflet::addLegend(
    pal = coverage_palette,
    values = ~vaccination_rate,
    title = "Simulated Coverage (%)",
    position = "bottomright",
    opacity = 0.8
  )

Part 8: Ethics and Accessibility

Discuss ecological interpretation, small cells, stigma, exact locations, missing data, and a noninteractive alternative.

Geographic information systems (GIS) can help public health professionals identify spatial patterns, assess resource distribution, and communicate potential health disparities. However, maps must be interpreted carefully to avoid misleading conclusions. One important consideration is the ecological fallacy, which occurs when conclusions about individuals are drawn from population-level data. For example, a county with lower vaccination coverage does not necessarily indicate that every community or individual within that county has low vaccination uptake.

Small population sizes can also affect the reliability of public health estimates, particularly when a small number of observations produces unstable rates. Additionally, maps may unintentionally reinforce stigma if geographic areas are labeled as unhealthy or underserved without considering structural factors such as healthcare access, transportation, insurance coverage, and socioeconomic conditions. Protecting privacy is especially important when mapping sensitive health information or exact healthcare service locations.

Accessibility is another essential consideration in public health mapping. Maps should include clear titles, readable legends, distinguishable colors, and descriptions that explain their primary findings. A noninteractive alternative, such as a static map accompanied by a written summary or accessible data table, should also be available for individuals who cannot use interactive mapping features. Missing data should be represented separately rather than interpreted as zero coverage.

Finally, all vaccination rates, population estimates, and clinic locations in this laboratory exercise are simulated. They should not be used to make actual claims about Georgia counties or guide real-world public health decisions. Clearly identifying simulated data supports transparency, ethical communication, and responsible interpretation of geographic health information.
